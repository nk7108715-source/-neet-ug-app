# NEET UG Preparation App

A bilingual NEET preparation app in Hindi and English.

## Subjects
- Biology / जीव विज्ञान
- Physics / भौतिक विज्ञान
- Chemistry / रसायन विज्ञान

## Planned Features
- Student signup and login
- Chapter-wise MCQs
- Mock tests and score tracking
- Free and premium study content
- Ads and subscriptions

## Technology
Flutter and Firebase
