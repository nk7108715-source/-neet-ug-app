
# 🎓 NEET UG Champion

A mobile-friendly NEET UG preparation app for students.

## 📚 Subjects
- Biology
- Physics
- Chemistry

## ✨ Features
- Hindi and English language options
- MCQ practice
- Basic mock test demo
- Mobile-friendly design
- Premium courses planned for future updates

## 🛠️ Technologies
- HTML
- CSS
- JavaScript

## 🚀 Run the App
1. Open `index.html` in a web browser.
2. Choose English, Hindi, or Both.
3. Select a subject or start MCQ practice.

## 📱 Android App
This project currently provides a web-based starter version.
Android APK packaging will be added in a future step.

## 🔜 Planned Features
- Student signup and login
- Chapter-wise notes
- More NEET-level questions
- Full mock test series
- Firebase database
- Premium subscription
- Rewarded ads

## 💰 Budget
The project is being developed with a ₹0 upfront budget target.
Some services may have usage limits or require payment as the app grows.

## ⚠️ Important
This is an early demo. The included questions are for basic practice and do not represent a complete official NEET mock test.
